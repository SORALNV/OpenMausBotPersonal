# グループのメンバー別権限

グループ右上の「グループ設定」から、各メンバーの応答方法（既定・メンション時のみ・メンションなしでも応答・発言しない）、自発投稿、他Botのメンション呼出し、作業依頼を保存する。「カテゴリーをまたいだメンバー間の連携を許可」は、そのグループ内だけに適用する。サイドバーの配置は変えない。個別チャットの閲覧、参加していないBotへの連絡、コンピューター操作の承認は拡張しない。

既存グループの権限は自動で拡張しない。新規グループを所有者の画面から作るとカテゴリー間連携を有効にして作る。既存の自動生成されたBot同士の1対1チャネルは対象外。グループの共有設定は所有者または管理者だけが変更でき、稼働中のグループは停止か完了が必要。同時編集は世代番号で拒否する。

「メンションなしでも反応」は新着メッセージへの応答を有効にする設定であり、何もないときに延々と自走させる設定ではない。会話のホップ数・発言済みメンバーの制限、投稿回数・無人実行の承認は維持する。
