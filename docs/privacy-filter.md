# 登録語句の置換と復元

OpenAI privacy-filterによる自動検出・ローカルモデルの起動・モデル設定・厳格モードは削除した。モデルやPython環境をインストールする必要はない。登録していない氏名・住所・メール・電話・口座・秘密情報は自動検出しない。

Personalアプリの「設定」→「一般」→「登録語句の置換」で、置換先、複数の表記、「元に戻す際の表記」を登録する。例として「星野架空」「ほしのかくう」「Kaku Hoshino」を `⟦ユーザーA⟧` にまとめ、表示復元を「星野架空」に固定できる。文字列の完全一致で大文字・小文字・空白を区別し、長い表記を優先する。置換結果を別のルールで再置換しない。

取得ツールの語句置換と、定期実行の語句置換は別々に設定できる。通常の手入力チャットには自動適用しない。Google Chatの受信本文は登録語句だけを処理する。設定破損・対応表保存失敗・対象ツールの未対応バイナリなど、処理失敗時に原文へフォールバックしない。

設定は `~/.openmausbot-personal/private/settings.json`、対応表は同じディレクトリの `vault.json` に保存する（ファイル0600、親ディレクトリ0700）。対応表は暗号化されていないローカルデータなので、そのディレクトリへのアクセスを保護する。通常ログやGitには含めない。過去のモデルで発行済みの仮名も、対応表があれば会話の範囲内で表示復元できる。対応表を削除しない。

表示復元と復元下書きはMac内の明示操作に限定する。復元してAI・Google Chat・他ツールへ自動送信しない。送信・操作の既存の承認は変更しない。

旧設定の `modelDetectionEnabled` は、元ファイルを隣接する0600のバックアップへ保存してから除去する。旧 `/api/internal/privacy-filter` は410を返し、旧モデル要求を成功として扱わない。旧 `OMB_PRIVACY_MODE` の厳格モード指定では、保護が存在するように見せず起動を拒否する。過去にダウンロードしたモデルやPython環境は自動削除せず、実行コードから参照しない。

この置換機能は、CLIが独自に読むファイル・ブラウザ・通信、既存履歴や記憶、直接入力や未登録表記を網羅的に保護するものではない。検証手順は [登録語句と入力キー](verification/personal-tool-privacy.md) を参照。
